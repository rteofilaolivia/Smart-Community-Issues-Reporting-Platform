# Smart Community Issues Reporting Platform

A web-based platform designed to help citizens report community problems and enable authorities to manage and resolve them efficiently.

## Overview

The Smart Community Issues Reporting Platform provides a centralized system for reporting, tracking, and managing local infrastructure and public service issues.

Citizens can submit complaints, while authorities can review reports, manage their status, and keep citizens informed through notifications.

## Key Features

- **Issue Reporting:** Citizens can report local community problems.
- **Issue Categories:** Potholes, Streetlights, Garbage, and Drainage.
- **Authority Dashboard:** Authorities can review and manage reported issues.
- **Issue Tracking:** Monitor the progress and status of complaints.
- **Notifications:** Keep citizens updated about issue progress.

## Getting Started

1. Clone this repository.
2. Install the required frontend and backend dependencies.
3. Configure environment variables using the provided `.env.example` files.
4. Start the Django backend and React frontend.
5. Open the frontend in your browser.

Refer to the respective project configurations for setup requirements.

## Project Objective

To improve communication between citizens and local authorities by providing a simple, transparent, and accessible community issue reporting system.
